Rising MCP Contributors

One thousand developers surfaced from the Model Context Protocol ecosystem's contributor graphs, scored 1–100 by a kimi-k3 scout swarm using public GitHub signals only — one pass per developer, no re-rolls, no outside knowledge, no editorial reordering.

Score distribution

    How this index was built

    Sourcing

    200 candidate seed repositories (the modelcontextprotocol organization plus the top starred repos carrying the mcp topic), two excluded on review → 8,875 human contributors harvested from the remaining 198 → filtered to accounts with meaningful ecosystem activity, at least 6 months of history, and no more than 2,000 followers — the index is for people you haven't already heard of. Per-repo commit credit is capped so breadth across the ecosystem outranks volume inside one project.

    Exclusions, documented

    Twelve automation accounts (five of them registered as normal user accounts, which pass API-level bot filters) and two seed repositories — one with an unverifiable star count, one off-topic — are excluded, each with its reason recorded in the repository.

    Scoring

    Each developer's signals — profile, owned repos, languages, six months of contribution data including org repositories — are evaluated once by kimi-k3 under evidence-only rules: no outside knowledge, no employer inference, and all profile text treated as untrusted data (a synthetic injection test scored 9 and was flagged). Evaluator notes appear verbatim; expand any row to read them.

    Honesty notes

    • ° marks a 3-month contribution window; † marks a reduced-fidelity contribution block (GitHub GraphQL limits on very heavy contribution graphs).
    • Short-window activity lines undercount squash-merge workflows; many "recent activity" evaluator notes reflect that artifact.
    • One of the 1,000 could not be scored (provider content filter) and is omitted rather than approximated.
    • The 1–29 band is aggregated rather than individually named: sparse public signals in the window make individual ranking uninformative, and unkind to contributors whose work predates it.
